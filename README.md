# 🚀 Daemon Dot

> A modern, decentralized web application template for IPFS-based projects.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![GitHub Pages](https://img.shields.io/badge/hosted%20on-IPFS-blue)](https://ipfs.io/ipfs/bafkreihm4b7qpi5tqys4cenpxumivz75ozymowkxdkstagmobtyii2kmma)

## 📋 Tentang Proyek

**Daemon Dot** adalah template proyek open source yang dirancang untuk membangun aplikasi web terdesentralisasi. Proyek ini memanfaatkan protokol IPFS untuk hosting dan distribusi konten yang aman dan efisien.

## ✨ Fitur Utama

- 🌐 **IPFS Integration** - Hosting terdesentralisasi di IPFS
- 📱 **Responsive Design** - Kompatibel dengan semua perangkat
- 🎨 **Modern UI/UX** - Interface yang user-friendly
- 🔐 **MIT Licensed** - Open source dan bebas digunakan
- 🧩 **Widget System** - Komponen yang dapat diperluas
- 🌍 **Multilingual Ready** - Mendukung berbagai bahasa

## 🛠️ Struktur Proyek

```
daemon-dot/
├── README.md              # Dokumentasi proyek
├── LICENSE                # Lisensi MIT
├── padam-akaun.html       # Fitur manajemen akun
├── .github/               # GitHub configuration
├── ICT/                   # Folder ICT resources
└── widget/                # Komponen widget
```

## 🚀 Mulai Cepat

### Prasyarat
- Browser modern dengan dukungan IPFS (optional: IPFS Companion extension)
- Text editor untuk mengedit file HTML/CSS/JavaScript

### Instalasi

1. **Clone Repository**
   ```bash
   git clone https://github.com/Lilmoki91/daemon-dot.git
   cd daemon-dot
   ```

2. **Buka di Browser**
   - Buka `padam-akaun.html` atau file HTML lainnya langsung di browser
   - Atau gunakan local server: `python -m http.server 8000`

3. **Akses via IPFS**
   - Gunakan IPFS gateway: https://ipfs.io/ipfs/bafkreihm4b7qpi5tqys4cenpxumivz75ozymowkxdkstagmobtyii2kmma

## 📖 Penggunaan

### Menambah Widget Baru

Letakkan file HTML/CSS/JS baru di folder `widget/`:

```html
<div class="widget-container">
  <!-- Konten widget Anda -->
</div>
```

### Mengelola Akun

Akses file `padam-akaun.html` untuk fitur manajemen akun pengguna.

## 📚 Dokumentasi
